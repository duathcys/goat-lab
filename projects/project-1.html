락앤락 데이터 파이프라인 구축

Python BigQuery GCP Data Pipeline

개요

락앤락 데이터 대시보드 구축 위에 데이터 파이프라인의 전체 적재 및 자동화 파이프라인을 설계·구축한 프로젝트입니다. 자사몰과 네이버 스마트스토어 데이터를 활용해 운영 대시보드에 필요한 지표들을 자동 수집·적재·정제하며, GA4와 스마트스토어 API를 통해 데이터를 수집하고 GCP 기반의 Cloud Function, BigQuery, Cloud Scheduler로 DataLake → DataWarehouse → DataMart로 이어지는 구조를 설계하고 자동화했습니다.

핵심 기능

  • Raw 데이터 → 정제 → 데이터 마트까지 단계별 데이터 파이프라인 설계
  • 데이터 정합성 검증 및 오류 발생 시 Slack 알람 전송 로직 구현
  • Google Cloud Scheduler + Cloud Function을 활용한 자동화 스케줄링 구축
  • Incremental Load 방식 전환으로 실시간·부분 업데이트 효율화
  • Raw Data 테이블 만료 설정(2개월 자동 삭제)으로 저장 공간 효율화
  • 실시간 대시보드 연동 최적화를 위한 적재 구조 개선

주요 성과

  • 데이터 수집부터 DataMart까지 전 과정 자동화
  • Slack 알람·자동 재시도로 운영 안정성 확보
  • Incremental Load 도입으로 저장 효율 개선
  • 실시간 대시보드 기반 마련

트러블슈팅

  • 불규칙한 GA4 Raw Data 적재 시간 대응
  • 자동 재시도 구조 구축 (오류 시 재시도 횟수·간격 설정)
  • Full Refresh → Incremental Load 전환
